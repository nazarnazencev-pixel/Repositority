## Вопрос 1

**Условие:**
Напишите запрос для получения списка предметов, для которых не назначено ни одного преподавателя.
Значения атрибутов таблиц могут быть `NULL`.
Используйте `EXISTS`.

**Ответ:**
```sql
SELECT * FROM SUBJECT S
WHERE NOT EXISTS (
    SELECT 1 FROM SUBJ_LECT SL WHERE S.SUBJ_ID = SL.SUBJ_ID
);
```

## Вопрос 2

**Условие:**
Напишите запрос, выбирающий сведения о каждом студенте, для которого в городе его проживания имеется хотя бы один университет, в котором он не учится.
Значения атрибутов таблиц могут быть `NULL`.
Используйте `EXISTS`.

**Ответ:**
```sql
SELECT * FROM STUDENT S
WHERE EXISTS (
    SELECT 1 FROM UNIVERSITY U
    WHERE U.CITY = S.CITY AND U.UNIV_ID <> S.UNIV_ID
);
```

## Вопрос 3

**Условие:**
Напишите запрос, выполняющий вывод количества студентов, имеющих хотя бы одну неудовлетворительную оценку и проживающих в городе, не совпадающем с городом их университета.
Используйте `EXISTS`.

**Ответ:**
```sql
SELECT COUNT(*) AS student_count
FROM student s
WHERE EXISTS (
    SELECT 1
    FROM exam_marks em
    WHERE em.student_id = s.student_id
      AND em.mark < 3
)
AND EXISTS (
    SELECT 1
    FROM university u
    WHERE u.univ_id = s.univ_id
      AND u.city != s.city
);
```

## Вопрос 4

**Условие:**
Напишите запрос для получения списка университетов, в которых не работает ни один преподаватель (университетов, у которых отсутствуют записи в таблице `LECTURER`).
Значения атрибутов таблиц могут быть `NULL`.
Используйте `EXISTS`.

**Ответ:**
```sql
SELECT UNIV_NAME FROM UNIVERSITY U
WHERE NOT EXISTS (
    SELECT 1 FROM LECTURER L
    WHERE L.UNIV_ID = U.UNIV_ID
);
```

## Вопрос 5

**Условие:**
Требуется получить информацию о количестве часов и семестре для дисциплин, кроме тех, которые перечислены в списке: Биология, Химия, География, Физика, Литература, Математика.
Упорядочить список по названиям дисциплин.

**Ответ:**
```sql
SELECT SUBJ_NAME, HOUR, SEMESTER FROM SUBJECT
WHERE SUBJ_NAME NOT IN ('Биология', 'Химия', 'География', 'Физика', 'Литература', 'Математика')
GROUP BY SUBJ_NAME;
```

## Вопрос 6

**Условие:**
Напишите запрос, формирующий для успевающих студентов (имеющих оценки 3, 4, 5) список их идентификаторов, идентификаторов сданных ими предметов, и полученных ими оценок.

**Ответ:**
```sql
SELECT STUDENT_ID, SUBJ_ID, MARK
FROM EXAM_MARKS
WHERE MARK IN (3, 4, 5);
```

## Вопрос 7

**Условие:**
Напишите запрос для получения списка предметов, изучаемых в течение одного семестра.
Значения атрибутов таблиц могут быть `NULL`.

**Ответ:**
```sql
SELECT SUBJ_NAME, SEMESTER FROM SUBJECT S1

```

## Вопрос 8

**Условие:**
Требуется получить информацию о количестве студентов из городов, кроме тех, которые перечислены в следующем списке: Ростов, Воронеж, Липецк, Самара, Екатеринбург, Орел, Белгород.

**Ответ:**
```sql
SELECT CITY, COUNT(1) FROM STUDENT
WHERE CITY NOT IN ('Ростов', 'Воронеж', 'Липецк', 'Самара', 'Екатеринбург', 'Орел', 'Белгород')
GROUP BY CITY;
```

## Вопрос 9

**Условие:**
Требуется получить список дисциплин с их часами для весенних семестров в следующем порядке: номер семестра, название дисциплины, часы. Упорядочить список по номеру семестра.

**Ответ:**
```sql
SELECT SEMESTER, SUBJ_NAME, HOUR
FROM SUBJECT
WHERE SEMESTER % 2 = 0
ORDER BY SEMESTER;
```

## Вопрос 11

**Условие:**
Напишите запрос, выполняющий вывод количества студентов, имеющих только отличные оценки.
Значения атрибутов таблиц могут быть `NULL`.
Используйте `EXISTS`.

**Ответ:**
```sql
SELECT COUNT(DISTINCT E1.STUDENT_ID)
FROM EXAM_MARKS E1
WHERE EXISTS (
    SELECT 1
    FROM EXAM_MARKS E2
    WHERE E2.STUDENT_ID = E1.STUDENT_ID
)
AND NOT EXISTS (
    SELECT 1
    FROM EXAM_MARKS E3
    WHERE E3.STUDENT_ID = E1.STUDENT_ID
      AND (E3.MARK IS NULL OR E3.MARK != 5)
);
```

## Вопрос 12

**Условие:**
Напишите запрос, позволяющий вывести имя студента, идентификатор его университета, идентификатор студента и город проживания для всех студентов, обучающихся в вузах, имеющих рейтинг выше 300.
Значения атрибутов таблиц могут быть `NULL`.

**Ответ:**
```sql
SELECT NAME, UNIV_ID, STUDENT_ID, CITY FROM STUDENT S
WHERE EXISTS (
    SELECT UNIV_ID FROM UNIVERSITY U
    WHERE U.UNIV_ID = S.UNIV_ID AND RATING > 300
);
```
