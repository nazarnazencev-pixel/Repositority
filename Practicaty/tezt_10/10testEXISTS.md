# 10. Оператор EXISTS

## Вопрос 1

**Формулировка:**  
Напишите запрос для получения списка университетов, в которых не учится ни один студент.  
Используйте **EXISTS**.

**SQL-ответ:**
```sql
SELECT univ_name
FROM university u
WHERE NOT EXISTS (SELECT 1 FROM student s WHERE s.univ_id = u.univ_id);
```

**Тест `-- test`:**
```text
UNIV_NAME
---------------------------------------
Институт международной торговли и права
Новый университет
```

## Вопрос 10

**Формулировка:**  
Напишите запрос для получения списка предметов, изучаемых более чем в одном семестре.  
Используйте **EXISTS**.

**SQL-ответ:**
```sql
SELECT subj_name, semester
FROM subject s1
WHERE EXISTS (SELECT 1 FROM subject s2 WHERE s1.subj_name = s2.subj_name AND s1.subj_id <> s2.subj_id)
```

**Тест `-- test`:**
```text
SUBJ_NAME   SEMESTER
----------  --------
Математика  2
Математика  1
```
