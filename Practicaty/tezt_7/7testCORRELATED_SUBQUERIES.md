## Вопрос 1

**Формулировка:**
Напишите запрос для получения списка предметов (ID, наименование, часы, семестр), на изучение которых отведено максимальное количество часов среди всех предметов, изучаемых в том же семестре. Список упорядочить по семестрам.

**SQL-ответ:**
```sql
SELECT subj_id, subj_name, hour, semester
FROM subject s1
WHERE hour = (SELECT MAX(hour) FROM subject s2 WHERE s1.semester = s2.semester)
ORDER BY semester;
```

```sql
SELECT STUDENT_ID, SURNAME, NAME, UNIV_ID, KURS, (SELECT AVG(mark) FROM exam_marks em WHERE em.student_id = s.student_id)
```

**SQL-ответ:**
```sql
SELECT surname
FROM student s
WHERE student_id IN (
    SELECT student_id
    FROM exam_marks
    GROUP BY student_id
    HAVING MIN(mark) = 5
) AND city NOT IN (SELECT city FROM university u WHERE u.univ_id = s.univ_id);
```
